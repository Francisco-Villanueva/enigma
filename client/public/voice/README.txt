VOICE FILES FOR THE INTRO FILM
==============================
Put six mp3 files in this folder, named exactly like this (one per line of the call).
If a file is missing, that line falls back to the browser's own voice, so nothing breaks.

line-1.mp3  "Attention, team. This is a priority call."
line-2.mp3  "On 22 June 2022, an Antonov An-30M cargo plane lost both engines over Siberia."
line-3.mp3  "The crew made a forced landing in the woods, far from any town. Its location signal has gone silent."
line-4.mp3  "The core that processes that signal has failed. You are the six people who can bring it back."
line-5.mp3  "Every system you restore gives us a fragment of the aircraft's position. Put them together, and we find them."
line-6.mp3  "The clock is running. Good luck."

Tips for ElevenLabs: pick a deep, calm male "narrator / documentary" voice, stability a bit high,
and generate each line separately so the subtitles follow each audio's real length.
The radio effect (narrow band + light static) is added by the app, so export the clean voice.
